# APPS_SECRETARIA_CMEIS

Repositório com aplicativos e materiais gratuitos para apoiar o trabalho das secretarias escolares, com foco em uso prático, simplicidade e autonomia da equipe.

## 🎯 Objetivo do projeto
Este projeto organiza ferramentas úteis para escolas públicas, priorizando:
- uso gratuito;
- fácil download e execução;
- documentação clara para treinamento da equipe;
- colaboração comunitária (GitHub aberto).

> **Contexto:** o projeto já está em fase de testes com outros apps úteis e gratuitos para escolas.

---

## 📥 Como baixar e usar

### Opção 1 — Download rápido
1. Clique no botão verde **Code**.
2. Clique em **Download ZIP**.
3. Extraia os arquivos no computador.
4. Abra os arquivos/documentos conforme a necessidade da equipe.

## 🤝 Contribuição (GitHub amigável)
Para facilitar contribuições de quem não é da área técnica:

1. Abra a aba **Issues** para relatar problema ou sugerir melhoria.
2. Use títulos objetivos (ex.: `Erro no passo 1.8 do manual`).
3. Se possível, anexe print da tela e descreva o passo a passo.
4. Para editar textos, use o botão de lápis no próprio GitHub e envie um **Pull Request**.

## ✅ Boas práticas para equipes escolares
- Mantenha os arquivos do projeto em uma pasta compartilhada da escola.
- Defina um responsável por revisar atualizações mensais.
- Use o manual como base de formação interna para novos servidores.
